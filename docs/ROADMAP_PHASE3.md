# Roadmap Phase 3 – Aufwändige Zusatzfunktionen

**Voraussetzung:** Phase 2 abgeschlossen (v1.0 stabil).

**Ziel:** Das Programm um ambitionierte Funktionen erweitern, die deutlich mehr Aufwand erfordern oder auf Phase-2-Features aufbauen.

**Milestone:** offen (kein fester Versionsplan).

---

Features haben keine feste Reihenfolge.
**Feature-Blöcke** kennzeichnen Abhängigkeiten – zuerst das obere Feature, dann das untere.

Typische Phase-3-Themen — alle optional, je nach Projekt-Ausrichtung:

- **Mehrsprachigkeit (i18n)** — Infrastruktur + erste Übersetzung + Framework für weitere Sprachen
- **Öffentliche Veröffentlichung** — Code-Kommentare-Sprache, Plattform-Kompatibilität, Release-Vorbereitung
- **Plattform-Portierung** — macOS / Linux / Mobile (wenn ursprünglich Windows-only)
- **Integrierte Viewer / Editoren** — was vorher externe Tools erledigen, inline übernehmen
- **Verlaufs-/Analyse-Funktionen** — Nutzungs-History, Statistik-Ansichten, Export
